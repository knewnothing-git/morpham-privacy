Privacy Policy

MorphAM — DfAM analysis API · Last updated 27 September 2026

The short version Geometry you upload for analysis is never kept. Each file is written to a temporary location, measured, and deleted as soon as the analysis finishes — including when the analysis fails. Your part files are not stored, not reused, not used to train anything, and not shared with anyone.

Who operates this service

MorphAM is operated by Yogesh Choudhary, an independent developer based in Pune, India. The service is available at morpham-api.fly.dev.

What is uploaded, and what happens to it

When you call /v1/analyze, your STL or STEP file is streamed to a temporary file on the server, measured, and then deleted. The deletion runs in a finally block, so the file is removed whether the analysis succeeds, fails, or is rejected for being oversized.

  • Geometry is not written to any database.
  • Geometry is not retained after the response is returned.
  • Geometry is not used to train models or improve the service.
  • Geometry is not shared with, sold to, or disclosed to third parties.

The analysis result — wall thickness, overhang areas, support volume, orientation ranking — is returned to you and not stored server-side.

What is stored

Two things are kept in a database, and only these:

  • API key records. When you request a key, we store the generated key, the email address you supplied, your tier, your monthly quota, a count of analyses used, and the time the key was created. The email is used to identify the key holder and to contact you about the service.
  • Large-part waitlist entries. If you submit the waitlist form, we store the email address, company name, approximate file size, and part type you provided, along with the submission time.

Filenames are echoed back in your own analysis response but are not written to the database.

Hosting and logs

The service runs on Fly.io infrastructure in the Mumbai (bom) region. Fly.io processes network traffic on our behalf as a hosting provider; their handling of that traffic is governed by their own privacy terms. Standard server logs may briefly record request metadata such as IP address, timestamp and endpoint, as any web server does. These logs are not used to build profiles and are not combined with your uploaded geometry.

Cookies and tracking

The MorphAM site sets no tracking cookies and runs no third-party analytics, advertising or fingerprinting scripts. The browser viewer performs its analysis by calling the same API described above.

Your rights

You can ask for a copy of what is held about you, ask for it to be corrected, or ask for your key record and any waitlist entry to be deleted. Deletion removes the record entirely; since no geometry is retained, there is nothing further to erase. Requests are handled within 30 days.

Data retention

Key records are kept while the key is in use. Waitlist entries are kept until the large-part feature ships or you ask for removal, whichever comes first. Uploaded geometry is retained only for the duration of a single request.

Children

MorphAM is a tool for manufacturing professionals and is not directed at children. We do not knowingly collect information from anyone under 16.

Changes

If this policy changes in a way that affects how your data is handled, the date at the top of this page will be updated. Material changes affecting existing key holders will also be sent by email.
